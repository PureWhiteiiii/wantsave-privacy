我全都要 WantSave · Microsoft Edge 基础版 1.0.0

隐私政策

发布者：WantSave · 生效及更新日期：2026-10-19

WantSave 在你的浏览器中发现、下载和合并媒体，并保存本地任务以便恢复。扩展没有发布者运营的媒体上传或行为统计服务。本网站由 GitHub Pages 托管；你主动发送的支持邮件会由发布者接收。以下分别说明这些数据如何处理。

1. 适用范围

本政策适用于“我全都要 WantSave”1.0.0 Microsoft Edge 基础版、本隐私政策网站，以及你通过支持邮箱向 WantSave 提交的问题。基础版提供网页视频、音频与图片保存、支持的音视频合并和本地下载任务恢复。

当前基础版没有扩展账号、购买、订阅、广告、遥测或本地 agent/MCP 联动。仅保存你有权下载的内容；原网站的访问条件和隐私政策仍然适用。

2. 扩展会处理的数据

  • 网页和媒体信息：当前网页及相关框架的地址、标题、媒体元素、媒体链接、播放列表、播放信息和可用画质。
  • 媒体网络响应：用于识别媒体的请求地址、来源框架、响应类型、文件名、文件大小、来源地址和发现时间。
  • 本地下载任务：任务标题、必要的规范来源信息、所选画质、状态、进度、时间和下载记录标识，以及完整取得的媒体流、片段或合并文件缓存。
  • 设置：是否在视频附近显示下载按钮。

这些数据用于发现和保存媒体、展示任务、检查保存状态及恢复任务。页面下载按钮开关只控制页面入口；后台媒体发现仍可能在获授权网页运行。你可通过 Microsoft Edge 的扩展管理页面限制网站访问或禁用扩展。

3. 本地存储、保留与删除

按钮设置存储在当前 Microsoft Edge 配置的本地扩展存储中。网络媒体候选和部分含临时参数的来源记录保存在浏览器会话存储中；相关媒体候选在页面导航或关闭后清理，会话数据会在浏览器会话结束时清理。

任务记录和媒体缓存保存在扩展本地数据库中，供关闭任务页或重启 Microsoft Edge 后恢复使用，并保留至你在“任务列表与恢复”中清除任务。临时链接失效或含查询参数的来源未保留时，恢复可能需要重新获取或重新提供链接。尚未完整取得的流或片段会重新下载。

清除任务和缓存不会删除已经保存到电脑的文件。磁盘文件与 Microsoft Edge 下载记录由你通过系统和浏览器管理。卸载扩展或清除扩展数据会使本地设置和缓存不可用。

4. 与原网站和媒体服务器的通信

下载直接请求你选择的原网站、播放列表及其媒体分发服务器。Bilibili 发现功能还会访问原站页面和播放信息接口。这些服务会接收完成请求所需的信息，例如 IP 地址、请求地址和请求头，并按其自身政策处理。

扩展不直接读取、保存或导出浏览器 Cookie。部分原站请求可能由 Microsoft Edge 根据站点和隐私设置自动附带已有凭证。所选资源的网络协议取决于原地址；扩展没有独立的登录、密码或支付收集表单。

5. 数据用途与共享

扩展不会把媒体、下载任务或浏览活动上传到发布者运营的数据收集服务，不使用 Microsoft Edge 同步存储。WantSave 不出售这些数据，不将其用于广告、信用评估、贷款或与媒体下载和本地任务恢复无关的目的。提供下载功能所需的原站通信见上一节。

WantSave 通过 Microsoft Edge 接口取得的信息只用于媒体下载和本地任务恢复，遵循 Microsoft Edge 扩展开发者政策。

6. 本网站与 GitHub Pages

本网站为 GitHub Pages 托管的静态网页。网站没有由 WantSave 添加的统计脚本、广告、跟踪像素或登录功能。根据 GitHub 的说明，访问 GitHub Pages 时，GitHub 会为安全目的记录和保存访问者 IP 地址；这与扩展的本地媒体处理是两项独立的数据处理。

详见 GitHub Pages 数据收集说明和 GitHub 隐私声明。

7. 支持邮件

如果你主动给支持邮箱发邮件，WantSave 会收到你的发件地址、邮件内容及你自行附加的信息，用于答复和处理该问题。邮箱服务商也会按其政策处理邮件。支持邮件在处理问题及必要后续沟通所需期间保留，你可通过下方邮箱提出删除请求。

反馈通常只需提供扩展版本、操作步骤和错误提示。请勿附上密码、验证码、私人媒体或带访问令牌的完整链接。

8. 权限如何使用

权限用途
网站访问、scripting发现媒体、显示页面下载入口，读取播放信息与画质。
webRequest识别媒体网络响应，为下载列表提供候选来源。
downloads保存所选媒体、检查下载状态、取消下载和定位文件。
storage保存本地按钮设置、会话来源和临时请求规则信息。
declarativeNetRequestWithHostAccess为所选 Bilibili 媒体请求临时设置必要 Referer，操作结束后移除规则。
