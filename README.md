# WantSave privacy website

Publisher: **WantSave**. Product: WantSave 1.0.0 basic Chrome extension.

This directory is dedicated to the public privacy website. The browser extension, download test data, browser profiles and project reports do not belong in this repository.

## Publisher and contact

Publisher: **WantSave**. Public support email: **wantsave.help@gmail.com**. GitHub owner: **PureWhiteiiii**. These details were confirmed by the owner on October 19, 2026.

## Deployment

Publish only `index.html`, `privacy.html`, `privacy-en.html`, `style.css`, `.nojekyll` and this README to the dedicated public repository `PureWhiteiiii/wantsave-privacy`. If that repository already exists, inspect it before making changes.

In Settings → Pages, use Deploy from a branch, branch `main`, folder `/ (root)`. Enable HTTPS when the hosting service makes it available. Verify the actual public homepage, both policy pages and both language links before entering the privacy URL in Chrome Web Store.

Expected addresses after successful deployment:

- Home and support: https://purewhiteiiii.github.io/wantsave-privacy/
- Chinese privacy policy: https://purewhiteiiii.github.io/wantsave-privacy/privacy.html
- English privacy policy: https://purewhiteiiii.github.io/wantsave-privacy/privacy-en.html

These addresses must be verified after deployment. The English policy URL is suitable for the store's single Privacy policy URL field and links to Chinese. The deployment evidence remains in the local project reports, outside this public repository.

Creating the mailbox, entering credentials, completing verification and accepting account terms are performed by the owner. Chrome Web Store submission remains out of scope.
